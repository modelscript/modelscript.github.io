Get Started Fast

Quick Start

From installation to computable digital thread simulation and rendering in under two minutes with the unified msc CLI.

1

Install the CLI

Install the unified command-line toolchain globally via npm.

bash
$ npm install -g @modelscript/cli
2

Flatten a Hierarchical Model

Lower Modelica classes to Differential Algebraic Equations with arena-native speed.

bash
$ msc flatten Modelica.Electrical.Analog.Examples.CauerLowPassAnalog path/to/MSL
3

Simulate ODE / DAE System

Execute numerical simulations with automatic index reduction and BLT partitioning.

bash
$ msc simulate BouncingBall model.mo --stop-time 5
4

Render Interactive SVG Diagram

Generate crisp vector diagrams from Modelica visual annotations.

bash
$ msc render MyModel model.mo > diagram.svg

Containerized Deployment

Run with Docker

Spin up the complete simulation API and Morsel environment locally with zero dependencies.

docker-compose
# Pull the pre-built multi-arch images
docker pull ghcr.io/modelscript/api:latest
docker pull ghcr.io/modelscript/morsel:latest

# Launch backend simulation server & interactive web UI
docker compose up -d
