How it works

One computable digital thread, from import to evidence

The same compiler core powers the CLI, the browser IDE, VS Code, and CI, so every step is scriptable and reproducible.

Installnpm install -g @modelscript/cli
~/project — msx import
# Translate a Simulink block diagram to Modelica
$ msx simulink to-modelica Suspension.slx --out=Suspension.mo
# Project AUTOSAR software components into SysML v2
$ msx autosar to-sysml Steering.arxml --out=Steering.sysml
Outputs.slx.arxml.pscx.step.sysml
~/project — msx analyze
# Lint an entire polyglot workspace for CI
$ msx lint ./models ./requirements --format json
# Semantic diff for code review
$ msx diff old/Plant.mo new/Plant.mo
OutputsJSON diagnosticsLSPPR diff
~/project — msx simulate
# Stiff DAE with sparse symbolic Jacobians
$ msx simulate RLC_Circuit circuit.mo --stop-time 10.0 --solver rodas4p --jacobian sparse --format csv
# Monte Carlo uncertainty study
$ msx mc RLC_Filter filter.mo
OutputsCSV trajectoriesSurrogatesMonte Carlo
~/project — msx verify
# Contract verification with a SARIF report
$ msx verify BrakingController brake.mo --format sarif --report results.sarif
# Grid-code compliance from a PSCAD project
$ msx pscad verify-ieee2800 SolarPlant_250MW.pscx --tstop 3.0 --step 20us
OutputsSARIFIEEE 2800EN 14363nuXmv / SMT-LIB2
~/project — msx deliver
# FMI 3.0 co-simulation FMU with an embedded WebAssembly binary
$ msx fmu DC_Motor motor.mo --fmi-version 3 --type cs --wasm --output build/DC_Motor.fmu
# Render a SysML v2 internal block diagram
$ msx render SpacecraftPower spacecraft.sysml --view IBD --theme blueprint -o ibd.svg
OutputsFMI 2.0 / 3.0SSPSVGnpm registry

Under the hood

Compiler-grade engineering, documented in the open

Every algorithm is documented in the architecture and algorithms catalog, so you can read exactly how your models are compiled and solved.

SPPF · WASM

Incremental GLR parsing

A native WebAssembly GLR parser generator with incremental reparsing, fast enough to run on every keystroke in the IDE.

Memoized DAG

Salsa query engine

Memoized, dependency-tracked semantic queries recompute only what changed across multi-file workspaces.

SoA Linear Memory

Arena DAE flattening

Hierarchical models are lowered straight into a struct-of-arrays DAE arena in linear memory, with no intermediate AST.

BLT · Tearing · IDA

Structural analysis & solvers

Pantelides index reduction, Tarjan BLT, and Cellier–Elmqvist tearing, plus SUNDIALS, BDF, and Rosenbrock integrators.

Collocation · NLP

Optimization

Direct collocation for optimal control and parameter estimation, with bounds, constraints, and custom objectives.

Bi-directional Sync

Triple graph grammars

Bidirectional synchronization links SysML v2, Modelica, STEP, and domain formats into one hypergraph.

SMT · CHC / IC3

Formal verification

Nelson–Oppen theory combination, CHC/IC3, and abstract interpretation prove properties of hybrid systems.

Deterministic Δt

SIL & real-time HIL

Deterministic WebAssembly runtimes for software-in-the-loop and hardware-in-the-loop execution.
