CLI Commands Reference ​

This reference documents every command, subcommand, and flag registered in @modelscript/cli (apps/cli/src/main.ts and apps/cli/src/commands/). All commands can be invoked via modelscript or its shorthand alias msx, and any command can be accelerated with the global --daemon flag.

Compilation, Simulation & Optimization ​

compile / flatten ​

Compiles and flattens a hierarchical Modelica class into a canonical Differential-Algebraic Equation (DAE) representation in linear WebAssembly memory (DAEBuilder). flatten is an exact alias for compile.

bash
msx compile <name> <paths...>
msx flatten <name> <paths...>
OptionTypeDefaultDescription
-L, --modelica-pathstringdirectories to search for Modelica libraries (colon-separated)
-F, --flattenerts | wasm | hybrid | diff"hybrid"Flattener backend: 'ts' (reference TS), 'wasm' (zero-GC kernel), 'hybrid' (WASM with TS fallback), or 'diff' (parity comparison)
--timingbooleanfalsereport timing information for each stage as JSON to stderr
--memory-profilebooleanfalseprofile memory usage across phases and report as JSON to stderr
bash
# Flatten a model using the hybrid WASM kernel with timing breakdowns
msx flatten Modelica.Electrical.Analog.Examples.ChuaCircuit -L ./libraries --timing

instantiate ​

Instantiates a Modelica class via the Salsa QueryEngine and prints the resolved component hierarchy, inherited modifications, and bindings prior to DAE index reduction.

bash
msx instantiate <name> <paths...>

simulate ​

Compiles a model, performs Block Lower Triangular (BLT) Pantelides index reduction and tearing, and executes a numerical time-domain or steady-state simulation locally or on a remote Slurm HPC cluster.

bash
msx simulate <name> [paths..]
OptionTypeDefaultDescription
-o, --outputstringoutput file path for simulation results
--start-timenumberoverride experiment start time
--stop-timenumberoverride experiment stop time
--tolerancenumberoverride experiment tolerance
--interval, --step-size, --output-intervalnumberoverride experiment output interval / step size
--formatcsv | json | none"csv"output format
--solvereuler | rk4 | dopri5 | tsit5 | trbdf2 | rodas4p | bdf | auto | cvode | webgpu"dopri5"ODE solver to use
--interface-typecs | me | autoFMI interface type when simulating an FMU: 'cs', 'me', or 'auto'
--start-valuestring[]override FMU variable start value as name=value (repeatable)
--input-filestringCSV file providing time-varying input trajectories (time,u1,u2,...)
--output-variablestring[]variable name(s) to record in FMU simulation output (repeatable)
--initial-fmu-state-filestringrestore serialized FMU state from file before stepping
--final-fmu-state-filestringsave serialized FMU state to file after simulation finishes
--log-fmi-callsbooleanfalselog all FMI C API calls and logger callbacks to stderr
--realtimenumberrun simulation in real-time mode with given scale factor (e.g., 1.0 for 1x)
--enginejs | arena | wasm | c | jit"js"simulation backend: js (pure JavaScript), arena (arena-native DoD), wasm (WebAssembly via emcc), c (native compiled), jit (in-memory JIT)
--jitbooleanfalseenable in-memory JIT compilation engine (sub-15ms execution)
--timingbooleanfalsereport timing information for each stage as JSON to stderr
--memory-profilebooleanfalseprofile memory usage across phases and report as JSON to stderr
--jacobiandense | sparse | fd"sparse"Jacobian calculation method
-F, --flattenerts | wasm | hybrid | diff"hybrid"Flattener backend: 'ts' (reference TS), 'wasm' (zero-GC kernel), 'hybrid' (WASM with TS fallback), or 'diff' (parity comparison)
--steady-statebooleanfalseSolve steady-state initial equilibrium only without time integration
--cloudbooleanfalsedispatch simulation to ModelScript Cloud HPC cluster
--profilestring"standard"cloud compute profile (standard, high-memory, gpu-a100, hpc-mpi-64)
--asyncbooleanfalsesubmit cloud job asynchronously and return immediately with Job ID
--poll-intervalnumber1500polling interval in milliseconds for cloud simulation status
--output-dirstring"./results"directory to write downloaded simulation result file
--api-urlstringoverride ModelScript API base URL
bash
# Run a stiff DAE simulation using the 4th-order Rosenbrock solver and sparse symbolic Jacobians
msx simulate RLC_Circuit circuit.mo --stop-time 10.0 --solver rodas4p --engine arena --jacobian sparse --format csv > trajectory.csv

# Dispatch a heavy multi-domain simulation to the Cloud HPC cluster
msx simulate ThermalGrid plant.mo --cloud --profile high-cpu --stop-time 3600 --output-dir ./runs/thermal

optimize ​

Formulates and solves a nonlinear Dynamic Optimization / Optimal Control Problem (OCP) over a flattened DAE using direct collocation and sequential quadratic programming (SQP).

bash
msx optimize <name> <paths..>
OptionTypeDefaultDescription
--objectivestringcost integrand expression (e.g. "u^2")
--controlsstringcontrol variable names (comma-separated)
--control-boundsstringcontrol bounds as var:min:max (comma-separated)
--start-timenumberoverride start time
--stop-timenumberoverride stop time
--num-intervalsnumber50number of collocation intervals
--tolerancenumber0.000001NLP convergence tolerance
--max-iterationsnumber200maximum SQP iterations
--formatcsv | json"csv"output format
bash
msx optimize EV_BatteryPack vehicle.mo \
  --objective energyLoss \
  --controls currentCommand \
  --control-bounds "currentCommand:-200:200" \
  --stop-time 600 \
  --num-intervals 100 \
  --format json > optimal_profile.json

grad ​

Computes forward, adjoint, or central finite-difference parameter sensitivities (∇pJ) of scalar objective metrics with respect to model parameters.

bash

OptionTypeDefaultDescription
--paramsstringcomma-separated list of parameter names to differentiate
--targetstringtarget state variable name to compute terminal sensitivity for (default: first state)
--start-timenumberoverride experiment start time
--stop-timenumberoverride experiment stop time
--stepnumbercommunication step size
--jsonbooleanfalseoutput results as JSON

surrogate ​

Executes a Design of Experiments (DoE) campaign over a physics model, trains a Reduced-Order Model (ROM) surrogate, attaches convex-hull/bounding-box extrapolation guardrails, and exports standalone C, ONNX, or Modelica .mo blocks.

bash
msx surrogate <name> [paths..]
OptionTypeDefaultDescription
--inputsstringinput parameter names (comma-separated)
--input-boundsstringinput bounds as var:min:max (comma-separated)
--outputsstringoutput variable names (comma-separated)
--strategyfull-factorial | latin-hypercube | sobol | central-composite"latin-hypercube"Design of Experiments (DoE) sampling strategy
--num-samplesnumber50number of samples to generate
--architecturemlp | polynomial | rbf"mlp"Reduced Order Model (ROM) architecture
--start-timenumberoverride start time
--stop-timenumberoverride stop time
--formatc | onnx | mo | all"c"target export format: C/WASM ('c'), ONNX graph ('onnx'), Modelica block ('mo'), or all ('all')
--from-onnxstringpath to external ONNX JSON model file to import instead of training from Modelica source
--extrapolation-guardrailsbooleantrueembed Modelica assertion guardrails for input bounds
--extrapolation-levelwarning | error"warning"severity level of Modelica extrapolation assertions
--extrapolation-flagbooleantrueemit Boolean isExtrapolating output variable in Modelica
--out-filestringoutput file name (defaults to <model>_surrogate.<ext>)
--replace-componentstringname of component declaration in Modelica model to replace with surrogate
--replace-outstringoutput path for modified Modelica model with replaced component
--reportstring"report.json"output report JSON file
bash
msx surrogate HeatExchanger thermal.mo \
  --inputs "massFlow,inletTemp" \
  --input-bounds "massFlow:0.1:5.0,inletTemp:280:380" \
  --outputs "outletTemp,pressureDrop" \
  --strategy sobol \
  --num-samples 128 \
  --architecture mlp \
  --format all \
  --out-file build/hx_rom

mc ​

Runs high-throughput Monte Carlo uncertainty propagation across stochastic parameter distributions using worker threads and the linear-memory WASM evaluator.

bash
msx mc <name> <paths..>
OptionTypeDefaultDescription
--runsnumber1000Number of Monte Carlo runs
--threadsnumber1Number of parallel threads
--paramsstringRandom variables in format name:dist:arg1:arg2 (comma-separated)
--seednumberPRNG seed
--lhsbooleanfalseUse Latin Hypercube Sampling
--formatcsv | json"json"Output format
--outputstringOutput file path (defaults to stdout if not provided)
--enginewasm | js"wasm"simulation backend: wasm or js
bash
msx mc RLC_Filter filter.mo \
  --params "R:gaussian:100:5,C:uniform:1e-6:1.2e-6" \
  --runs 5000 \
  --lhs \
  --threads 8 \
  --seed 42 \
  --output mc_summary.json

csg ​

Extracts Constructive Solid Geometry (CSG) primitives and kinematic frame transformations from a Modelica class, writes build/csg/execution_graph.json, and invokes the OpenCASCADE (@modelscript/cad) worker to generate 3D CAD meshes.

bash
msx csg <name> <paths...>

Linting, Formatting, Diffing & Compiler Inspection ​

lint ​

Executes the static analysis pipeline (WASM GLR parse validation, CST lint rules, Salsa semantic queries, unit checking, and control-flow analysis) across one or more files or directories.

bash
msx lint <path> [paths...]
OptionTypeDefaultDescription
-l, --languagestringFilter to specific language (e.g. modelica, sysml2, owl2, scad, ssp, cfd, fea, pscad, fortran, easy5, rocets, lps, sima, gtsuite)
-f, --formatterminal | json"terminal"Output format: terminal or json
--profileDL | EL"DL"OWL 2 ontology profile to validate against (DL or EL)
--strictbooleanfalseTreat warnings as errors
bash
# Lint an entire polyglot workspace and emit JSON for CI processing
msx lint ./models ./requirements --format json

parse ​

Parses a file using its registered native WebAssembly GLR parser (parser.wasm) and prints the concrete syntax tree (CST), node byte offsets, or parse errors.

bash

OptionTypeDefaultDescription

--encodingutf8 | utf16le | utf16be | utf32le | utf32be"utf8"Input encoding to use

Formats source files canonically using the grammar's CST-preserving pretty-printer while preserving comments and annotations.

bash

OptionTypeDefaultDescription
-w, --writebooleanfalseEdit files in place

-l, --languagestringExplicit language override (e.g. modelica, sysml2, scad, step)
--indent-sizenumber2Number of spaces per indentation level
--preserve-formattingbooleanfalsePreserve original token layout where grammar permits

Parses a source file into linear CST memory and unparses it back into text to verify lossless round-trip grammar rules.

bash

OptionTypeDefaultDescription

-l, --languagestringExplicit language override

Formal Verification, Safety & Test Synthesis ​

verify ​

Unified formal verification and simulation validation for SysML v2 and Modelica: decision tables, assume-guarantee contracts, state machines, and optional flowpipe reachability. Results can be emitted as terminal output or as JSON, CTRF, JUnit, SARIF, HTML, or DHF reports for CI/CD and compliance workflows.

bash
msx verify [target] [paths..]
OptionTypeDefaultDescription
--allbooleanfalseexecute all applicable formal verification stages
--decisionsbooleantrueverify decision table exhaustiveness and determinism
--contractsbooleantrueverify assume-guarantee contract compatibility and refinement
--state-machinesbooleantrueverify state machine and activity workflow soundness/deadlock-freedom
--flowpipebooleanfalseenable validated continuous/hybrid reachability flowpipes
--ordernumber4Taylor model flowpipe expansion order
--dtnumbertime step size in seconds for flowpipe reachability
--horizonnumbertime horizon (stop time) in seconds for flowpipe reachability
--initial-setstringinitial state set bounds (e.g. 'x=[0.9,1.1],y=[-0.1,0.1]')
--barriersbooleanfalseenable sum-of-squares barrier certificate synthesis
--falsifybooleanfalseenable adversarial requirement falsification
--simulationbooleantrueverify dynamic simulation trajectory requirements
--clearancebooleanfalseenable 3D CAD clearance and physical collision verification
--mcdcbooleanfalsesynthesize 100% MC/DC independent condition test pairs
--b2bbooleanfalseverify Back-to-Back MiL-vs-SiL equivalence against standalone C99
--b2b-tolnumber0.0001maximum allowable numerical tolerance between MiL and SiL
--b2b-compilergcc | clang | tcc | arm-none-eabi-gcc"gcc"host/target C compiler for SiL compilation
--b2b-dtnumberfixed integration step size in seconds for SiL RK4
--algorithmsbooleantrueexecute sound algorithmic abstract interpretation for zero RTEs
--formatterminal | json | ctrf | junit | sarif | html | dhf"terminal"output report format: terminal, json, ctrf, junit, sarif, html, or dhf
--reportstringwrite test report to specified file path
--exportstringcomma-separated list of formal spec export formats: smt2, nuxmv, ocra, mos
--export-dirstring"."target directory for exported formal specifications
-F, --flattenerts | wasm | hybrid | diff"hybrid"Flattener backend: 'ts', 'wasm', 'hybrid', or 'diff'
--enginewasm | js"wasm"simulation backend: wasm or js
--timingbooleanfalseoutput timing JSON to stderr
--update-hypergraphbooleanfalsesynchronize verification verdicts directly into digital thread hypergraph
bash
# Verify a controller and emit a GitHub Code Scanning SARIF report
msx verify BrakingController brake.mo --format sarif --report results.sarif
