MSC Adams Multibody Dynamics ​

ModelScript features comprehensive, native support for MSC Adams (.adm, .cmd), the classic industrial standard for mechanical systems simulation and multibody dynamics (MBD). Engineers can parse legacy Adams View command files and solver datasets, perform Grübler-Kutzbach spatial mobility analysis, evaluate 3D joint constraint residuals, and project mechanisms to modern SIMPACK and Modelica formats.

Capabilities & Supported Formats ​

FormatExtensionDescription
Adams Solver Dataset.admNumerical dataset specifying rigid parts (PART), marker frames (MARKER), kinematic joints (JOINT), force elements (SPRINGDAMPER, BUSHING), and constraints.
Adams View Command File.cmdInteractive parametric command scripts defining mechanism geometry, design variables, and simulation runs.

Key Architectural Features ​

  • Lexer & Parser:
    • Robust deck ingestion supporting scientific notation (1.5D-03), inline comments (!), line continuations (...), and block cards.
    • Lossless serialization back to standardized .adm solver format via serializeAdams().
  • Spatial 3D Kinematics:
    • Full evaluation of Euler 3-1-3 and Tait-Bryan 1-2-3 rotation matrices.
    • Analytical joint constraint formulation for standard spatial joint primitives (Revolute, Spherical, Prismatic, Cylindrical, Planar, Universal).
  • Grübler-Kutzbach Mobility Analysis:
    • Calculates mechanism degrees of freedom (M=6(n−1)−∑ci).
    • Identifies redundant kinematic constraints and overconstrained multi-loop linkages.
  • Multibody Linters (M7301–M7310):
    • Flags missing ground parts, dangling marker references, unphysical inertia tensors violating the triangle inequality (Ixx+Iyy≥Izz), massless moving parts, and negative spring/damping parameters.
  • Cross-Domain Projections:
    • SIMPACK MBD: Maps parts, markers, and spatial joints to SIMPACK .spck XML models.
    • Modelica MultiBody: Synthesizes standard Modelica.Mechanics.MultiBody parts and joint components.

Command Line Interface (msx adams) ​

bash
msx adams <action> [files...] [options]
ActionDescriptionKey Options
inspectDumps part hierarchy, markers, joints, forces, and initial conditions.—
lintRuns structural validation, inertia verification, and kinematic sanity checks.—
mobilityEvaluates spatial degrees of freedom and overconstrained loops.—
to-simpackProjects Adams mechanism to SIMPACK XML (.spck).--out=<file.spck>
to-modelicaProjects Adams mechanism to Modelica.Mechanics.MultiBody.--out=<file.mo>
to-daeLowers kinematic and dynamic momentum equations into DAEBuilder arena.—

Examples ​

bash
# Calculate mechanism spatial degrees of freedom
msx adams mobility FourBarLinkage.adm

# Validate inertia tensors and marker references
msx adams lint LandingGear.adm

# Convert Adams dataset into SIMPACK XML format
msx adams to-simpack RobotArm.adm --out=RobotArm.spck

# Lower multibody equations into ModelScript DAE arena
msx adams to-dae ExcavatorMechanism.adm

Multibody Linters & Diagnostic Rules ​

CodeIdentifierSeverityDescription
M7301dangling-part-referenceErrorMarker or joint references a part ID that does not exist in the dataset.
M7302dangling-marker-referenceErrorJoint or force element references an undeclared marker ID.
M7303non-physical-inertia-tensorErrorMoments of inertia violate the triangle inequality (Ixx+Iyy<Izz) or are non-positive.
M7304massless-moving-partWarningNon-ground moving part has zero mass or zero principal inertia moments.
M7305coincident-joint-markersWarningTwo markers on a joint are coincident in position and orientation, which may cause kinematic singularity.
M7306overconstrained-mechanismWarningMobility analysis indicates overconstrained loops (M<0) requiring redundant constraint elimination.
M7307negative-spring-stiffnessErrorSpring-damper element defines negative stiffness K or negative damping coefficient C.
M7308missing-ground-partErrorMechanism does not declare an inertial ground reference frame (GROUND).
M7309unsupported-joint-primitiveWarningJoint card specifies an experimental or proprietary constraint type.
M7310zero-length-linkWarningDistance between base and joint markers on a moving part is zero.
