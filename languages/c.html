C Numerical & Embedded Engineering Integration (.c, .h) ​

@modelscript/c (languages/c) provides native WebAssembly GLR parsing, procedural simulation step compilation, automated Modelica external "C" header binding, continuous DAE lowering, and static analysis diagnostics for ANSI C / C99 engineering blocks, Simulink C MEX S-functions, and PSCAD custom C components.

Supported Extensions & Standards ​

ExtensionStandard / FormatDescription
.cC99 / ANSI CControl algorithms, filter routines, ODE integration steps, and S-functions
.hC HeadersFunction prototypes, typedefs, and struct layouts for Modelica external bindings

Key Capabilities ​

1. WebAssembly GLR C Parser ​

  • Ahead-of-time compiled WebAssembly GLR parser generated by @modelscript/dsl with zero grammar conflicts.
  • Parses full C99 translation units, nested functions, struct/union/enum declarations, typedef names, control flow (if, while, for, do-while), pointer/array operators, and bitwise/arithmetic expressions.

2. Automated Modelica External "C" Bridge ​

  • Header Scraper (scrapeCHeader) extracts C prototypes, argument names, causalities, and struct fields from .h files.
  • Modelica Binder (bindCHeaderToModelica) auto-generates strongly typed Modelica functions with:
    modelica
    function motor_torque
  input Real current;
  input MotorParams p;
  output Real y;
  external "C" y = motor_torque(current, p)
    annotation(Include = "#include \"motor.h\"");
end motor_torque;

3. Zero-Allocation Simulation Step Compiler ​

  • Compiles procedural C control blocks and discrete filters into low-overhead execution closures executing 100,000 steps in < 30ms without heap allocations.
  • Direct mapping to pre-allocated typed arrays: statesReal (Float64Array) and statesInt (Int32Array).
  • Built-in support for standard <math.h> mathematical functions (sin, cos, tan, asin, acos, atan, atan2, exp, log, log10, sqrt, fabs, pow, fmin, fmax, floor, ceil).

4. Direct DAE Subroutine Lowering ​

  • Translates ODE continuous state derivatives (dx[i] = ... / der_x = ...) directly into continuous states der(s_i) in @modelscript/runtime's IDaeBuilder linear memory arena.
  • Enables Simulink continuous S-functions and PSCAD C segments to integrate directly into continuous DAE and hybrid ODE solvers.

Static Analysis & Safety Linter Rules ​

The C analyzer surfaces common numeric defects, memory safety concerns, and algorithmic cycles (M8401–M8410):

M8401uninitialized-variablewarningLocal variable may be read before being assigned or initialized.
M8402constant-division-by-zeroerrorDivision or modulo by constant zero detected in arithmetic expression.
M8403array-bounds-overflowerrorStatic array subscript index exceeds declared dimension bound (i≥N).
M8404unreachable-codewarningUnreachable statements detected following unconditional return, break, or goto.
M8405assignment-in-conditionalwarningAssignment operator = used inside conditional expression instead of comparison ==.
M8406algebraic-dependency-cycleerrorProcedural algebraic loop / mutual cyclic variable assignment detected without state lag.
M8407null-pointer-dereferenceerrorDereference of statically known NULL pointer constant.
M8408function-prototype-mismatcherrorFunction definition signature conflicts with previously declared prototype.
M8409missing-return-valueerrorNon-void function reaches end of body without returning a value.
M8410implicit-lossy-conversioninfoFloating-point value implicitly assigned to integer without explicit cast.

CLI Usage ​

bash
# Lint C source files or headers
msx lint Controller.c

# Generate Modelica external "C" bindings from header
msx c to-modelica SensorDriver.h -o SensorDriver.mo
