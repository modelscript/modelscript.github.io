STEP (ISO 10303-21) ​

@modelscript/step (languages/step) provides a native WebAssembly GLR parser, assembly hierarchy extractor, AP242 Geometric Dimensioning & Tolerancing (GD&T / PMI) analyzer, and Modelica MultiBody kinematic synthesizer for ISO 10303-21 Clear Text Encoding of the Exchange Structure (.step, .stp, .p21).

Supported Extensions & Standards ​

ExtensionStandardScope
.step, .stp, .p21ISO 10303-21 (AP203, AP214, AP242)B-Rep solid geometry, product assembly trees (NEXT_ASSEMBLY_USAGE_OCCURRENCE), kinematic joints, and PMI/GD&T tolerances

Capabilities ​

  1. Zero-Dependency STEP Part 21 Parser: Parses HEADER; and DATA; sections, #id = ENTITY_NAME(...) instances, nested typed parameters, and enumeration tokens into linear memory.
  2. Assembly Hierarchy & Mass Properties (extractStepAssembly): Extracts PRODUCT_DEFINITION parts, NEXT_ASSEMBLY_USAGE_OCCURRENCE parent–child assembly trees, AXIS2_PLACEMENT_3D rigid-body frames, bounding boxes, and mass/inertia properties.
  3. AP242 PMI & GD&T Extraction (extractStepAssembly): Extracts datum features (DATUM, DATUM_FEATURE, DATUM_SYSTEM) and 10 geometric tolerance categories (StepGeometricTolerance in languages/step/src/extractor.ts) for 3D tolerance stack-up analysis (ToleranceStackOracle):
GD&T Tolerance KindSTEP AP242 Entity Name
flatnessFLATNESS_TOLERANCE
roundnessROUNDNESS_TOLERANCE / CIRCULARITY_TOLERANCE
cylindricityCYLINDRICITY_TOLERANCE
perpendicularityPERPENDICULARITY_TOLERANCE
parallelismPARALLELISM_TOLERANCE
positionPOSITION_TOLERANCE
surface_profileSURFACE_PROFILE_TOLERANCE
concentricityCONCENTRICITY_TOLERANCE / COAXIALITY_TOLERANCE
runoutCIRCULAR_RUNOUT_TOLERANCE / TOTAL_RUNOUT_TOLERANCE
generalGEOMETRIC_TOLERANCE (with TOLERANCE_VALUE / LENGTH_MEASURE_WITH_UNIT)
  1. Modelica MultiBody Kinematic Synthesis (mapStepToMultiBody): languages/step/src/multibody-mapper.ts translates STEP kinematic joints and AXIS2_PLACEMENT_3D transforms directly into Modelica.Mechanics.MultiBody components:
    • Kinematic Joints: Maps REVOLUTE_PAIR → Modelica.Mechanics.MultiBody.Joints.Revolute, PRISMATIC_PAIR → Joints.Prismatic, CYLINDRICAL_PAIR → Joints.Cylindrical, SPHERICAL_PAIR → Joints.Spherical, and PLANAR_PAIR → Joints.Planar with axis vectors n and connect(...) equations.
    • Static Frame Placements (MultiBodyFixedTranslation): Computes exact translation vectors r = {x, y, z} (converting MILLI to meters) and 3×3 orthonormal orientation matrices from AXIS2_PLACEMENT_3D axis (z^) and ref_direction (x^) vectors to emit Modelica.Mechanics.MultiBody.Parts.FixedTranslation and Parts.BodyBox / Parts.BodyCylinder components.

IDE & CAE Mesh Generation Actions ​

stepLanguage.actions (languages/step/src/language.ts) provides 6 built-in CAD/CAE workflows:

Action IDDescription
open_cad_viewerOpens the interactive 3D B-Rep & assembly viewer for the .step model
generate_multibodySynthesizes a Modelica.Mechanics.MultiBody .mo model from STEP assembly frames and joints
generate_fea_meshTessellates the STEP B-Rep solid into a 3D tetrahedral CalculiX .inp finite element mesh
generate_cfd_meshGenerates an unstructured .su2 surface/volume fluid mesh from the STEP geometry
create_fea_setupScaffolds a parametric .inpt CalculiX structural study linked to the STEP part
create_cfd_setupScaffolds a parametric .cfgt SU2 aerodynamic study linked to the STEP part

Dedicated step-mcp Server Tools ​

The @modelscript/step MCP server (languages/step/src/mcp/server.ts) exposes two specialized tools for AI engineering agents:

  • step_extract_entities: Parses a .step / .stp file and returns the structured assembly tree, AXIS2_PLACEMENT_3D coordinate frames, kinematic joints, and AP242 GD&T geometric tolerances.
  • step_to_multibody: Generates complete Modelica.Mechanics.MultiBody code (including World, Parts.Body, Parts.FixedTranslation, Joints.*, and connect(...) equations) from a STEP assembly.

Polyglot TGG Rules ​

@modelscript/step registers 5 bidirectional Triple Graph Grammar (TGG) rules in languages/step/src/language.ts:

Rule NameSource (step)Target LanguageTarget Construct
StepProductToSysML2PartDataEntity (PRODUCT)sysml2PartDef
StepPropertyToSysML2AttributeDataEntity (PROPERTY_DEFINITION)sysml2AttributeUsage
StepPlacementToSysML2PortDataEntity (AXIS2_PLACEMENT_3D)sysml2PortUsage
StepRevoluteJointToModelicaRevoluteDataEntity (REVOLUTE_PAIR)modelicaComponentClause (Modelica.Mechanics.MultiBody.Joints.Revolute)
StepPrismaticJointToModelicaPrismaticDataEntity (PRISMATIC_PAIR)modelicaComponentClause (Modelica.Mechanics.MultiBody.Joints.Prismatic)

CLI Usage ​

bash
# Parse and inspect the CST of an ISO 10303-21 STEP file
npx msx parse chassis.step

# Project a STEP assembly into a Modelica MultiBody model via TGG rules
npx msx polyglot project chassis.step --target modelica --out chassis.mo

# Verify cross-domain alignment between STEP CAD geometry and SysML v2 architecture
npx msx align chassis.step architecture.sysml
