GT-SUITE / GT-POWER Modeling (.gtm, .gtd, .gtx, .gt) ​

The @modelscript/gtsuite package (languages/gtsuite) provides native compilation, simulation, analysis, and multi-domain projections for Gamma Technologies GT-SUITE and GT-POWER 1D engine, powertrain, turbocharging, and thermo-fluid dynamic simulation models.

Supported File Specifications ​

ExtensionFormatKey Structural Features
.gtm / .gtdGT-SUITE Model DeckASCII and XML representations of cylinders, plenums, runners, valves, injectors, and turbochargers
.dat / .mapTabular Component MapsCompressor and turbine pressure ratio vs. corrected mass flow and efficiency performance maps
.gdx / .csvTrajectory ResultsCrank-resolved in-cylinder pressure, temperature, burn rate, and emissions time series

M9001cfl-stability-violationerrorDiscretized runner sub-volume CFL acoustic travel time exceeds integration step.
M9002compressor-surge-riskwarningOperating point is to the left of the compressor surge boundary.
M9003turbine-choke-limitwarningTurbine mass flow exceeds choked sonic flow limit.
M9004valve-timing-overlap-excesswarningIntake and exhaust valve overlap duration exceeds 90° crank angle.
M9005invalid-compression-ratioerrorCylinder compression ratio is non-physical (CR≤1.0 or CR>30.0).
M9006unconnected-plenum-porterrorIntake or exhaust plenum boundary port is open with no runner connected.
M9007intercooler-effectiveness-overflowerrorThermal heat exchanger effectiveness exceeds physical maximum (E>1.0).
M9008injector-delivery-mismatchwarningCommanded fuel mass delivery exceeds maximum injector flow capability.
M9009negative-friction-meperrorEngine friction mean effective pressure (FMEP) is negative.

Headless CLI Operations (msx gtsuite) ​

bash
# Print model summary
msx gtsuite summary cases/Turbo4Cyl.gtm

# Run pre-flight static analysis
msx gtsuite lint cases/Turbo4Cyl.gtm

# Run in-WASM transient thermodynamic simulation
msx gtsuite simulate cases/Turbo4Cyl.gtm --duration=0.5 --out=trajectories.csv

# Evaluate formal verification gates (BSFC, boost, emissions, knock)
msx gtsuite verify cases/Turbo4Cyl.gtm --max-bsfc=240.0 --max-boost=2.8 --max-nox=60.0

# Export vector schematic SVG diagram
msx gtsuite diagram cases/Turbo4Cyl.gtm --view=schematic --out=engine_schematic.svg

# Project to Modelica and SysML v2
msx gtsuite to-modelica cases/Turbo4Cyl.gtm --out=Engine.mo
msx gtsuite to-sysml2 cases/Turbo4Cyl.gtm --out=Engine.sysml
