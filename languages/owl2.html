OWL2 Ontology (.owl, .owl2, .ofn, .ttl) ​

@modelscript/owl2 (languages/owl2) brings formal ontological engineering, Description Logic (SROIQ(D)) reasoning, and SPARQL / Leapfrog Triejoin graph querying directly into the ModelScript compiler.

Supported Extensions & Formats ​

ExtensionFormat
.owl, .owl2, .ofnW3C OWL 2 Functional-Style Syntax (Prefix(...), Ontology(...))
.ttlRDF Turtle / Ontological Triple Assertions

lowerCstToAxioms(tree, sourceText) (languages/owl2/src/cst-lowering.ts) lowers the linear-memory CST into an arena-backed OntologyStore supporting over 35 OWL 2 DL axiom and class expression constructs:

Description Logic Tableau Reasoner & Leapfrog Triejoin ​

@modelscript/owl2 includes an in-memory SROIQ(D) Tableau Reasoner (TableauReasoner in languages/owl2/src/reasoner/) and a worst-case optimal Leapfrog Triejoin engine (executeBGP in languages/owl2/src/query/leapfrog.ts):

  1. Consistency & Satisfiability Checking: Detects unsatisfiable classes (DisjointClasses violations, cardinality contradictions, irreflexive/asymmetric cycles, negative property assertion conflicts) and surfaces exact source diagnostics (OWL2001–OWL2005).
  2. Justification & Explanation Tracing: Computes minimal unsatisfiability justifications (explain_inference) explaining why a class or individual violates ontology axioms.
  3. SPARQL & Multi-Way BGP Joins: Evaluates conjunctive Basic Graph Patterns (BGPs) in O(AGM bound) worst-case optimal time without materializing intermediate Cartesian products.

Interactive 2D Ontology Diagram & Bidirectional Writeback ​

languages/owl2/src/diagram/ provides an interactive 2D graph visualization and editing surface for OWL 2 ontologies:

  • Visual Graph Projection: Renders Class nodes, NamedIndividual instances, SubClassOf inheritance hierarchies, and ObjectPropertyDomain/ObjectPropertyRange directed edges.
  • Bidirectional CST Writeback (owl2Language.writeback): Adding/deleting nodes or edges in the diagram (add_node, delete_node, add_edge, delete_edge, rename_node, update_parameter) patches the Functional-Style .owl source text directly—inserting or removing Declaration(...), SubClassOf(...), or DataPropertyAssertion(...) axioms in place.

Dedicated owl2-mcp Server Tools ​

The @modelscript/owl2 MCP server (languages/owl2/src/mcp/server.ts) exposes five specialized tools to AI agents:

MCP ToolDescription
validate_system_consistencyParses an OWL 2 Functional Syntax ontology, runs the SROIQ Tableau Reasoner, and returns consistency status, unsatisfiable classes, and inferred SubClassOf hierarchy
query_ontology_sparqlExecutes a SPARQL SELECT WHERE query over the ontology's inferred RDF triple graph
query_ontology_bgpEvaluates a conjunctive Basic Graph Pattern (BGP) using the worst-case optimal Leapfrog Triejoin algorithm
explain_inferenceComputes formal axiomatic justifications explaining why an entailment holds or why a class is unsatisfiable
trace_fault_propagationTraces transitive fault propagation (TransitiveObjectProperty / causal links) from a starting component individual across the system topology

Command Line Interface (msx polyglot) ​

OWL2 ontologies can be queried, projected, and validated using ModelScript's polyglot digital thread commands:

bash
# Project OWL 2 DL class hierarchies and axioms into formal SysML v2 part definitions
msx polyglot project SpacecraftOntology.ofn --target=sysml2 -o Spacecraft.sysml

# Cross-query ontology symbols and digital thread twins in the unified Salsa index
msx polyglot query Spacecraft::ReactionControlPod --domain=owl2

# Verify losslessness and critical pair confluence across OWL 2 TGG synchronization rules
msx polyglot verify --strict
