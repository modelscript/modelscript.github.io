Touchstone RF & Signal Integrity (.sNp, .ts) ​

@modelscript/touchstone (languages/touchstone) provides high-performance zero-regex parsing, Vector Fitting rational macromodeling, Hamiltonian passivity enforcement, linear DAE lowering, and Modelica 3.x projection for Touchstone 1.0 & 2.0 multi-port RF, microwave, and high-speed digital interconnect decks.

Supported Extensions & Standards ​

ExtensionFormatDescription
.s1p1-Port NetworkReflection coefficient (S11) for antennas, terminations, and single-ended loads
.s2p2-Port NetworkTransmission (S21,S12) and reflection (S11,S22) for filters, amplifiers, transmission lines
.s3p, .s4p, .sNpMulti-Port NetworkMulti-pin connectors, differential transmission lines, crosstalk matrices
.tsTouchstone 2.0Advanced multi-port specification with mixed-mode S-parameters and per-port reference impedances

Key Capabilities ​

1. Multi-Format Parameter Formats ​

  • Parses multi-port frequency grids with automatic unit conversion (Hz, kHz, MHz, GHz) and parameter types:
    • S-Parameters (Scattering matrix)
    • Y-Parameters (Admittance matrix)
    • Z-Parameters (Impedance matrix)
    • H / G Parameters (Hybrid matrices)
  • Supports all standard data formats:
    • DB: Magnitude in decibels (20log10⁡|S|), phase in degrees (∠S)
    • MA: Linear magnitude (|S|), phase in degrees (∠S)
    • RI: Real and imaginary components (Re(S)+jIm(S))
  • Enforces strict Touchstone matrix ordering conventions (e.g., S21,S12 transpose ordering for 2-port networks).

2. Vector Fitting & Rational Macromodeling ​

  • Converts discrete frequency-domain tabulated measurements into continuous-time rational transfer functions via Vector Fitting:Sij(s)≈∑m=1Prms−pm+d+s⋅ewhere pm are complex conjugate pole pairs in the open left half-plane (Re(pm)<0), ensuring stability.
  • Synthesizes a state-space realization:x˙(t)=Ax(t)+Bu(t),y(t)=Cx(t)+Du(t)which lowers directly into ODE time-domain solvers without inverse FFT convolution lag.

3. Passivity Verification & Hamiltonian Matrix ​

  • Verifies that the N-port network does not generate net energy across all frequencies:∥S(jω)∥2≤1∀ω∈[0,∞)
  • Computes the eigenvalues of the Hamiltonian matrix:H=[A+B(I−DTD)−1DTCB(I−DTD)−1BT−CT(I−DDT)−1C−(A+B(I−DTD)−1DTC)T]where purely imaginary eigenvalues identify exact passivity violation frequency crossover points.

4. Direct DAE Lowering & Modelica Projection ​

  • Lowers state-space companion matrices directly into @modelscript/runtime's DAEBuilder SoA linear memory arena.
  • Projects multiport networks into Modelica.Electrical.Analog pin networks for joint electro-mechanical and power electronic simulations (@modelscript/spice).

CLI Usage ​

bash
# Inspect Touchstone port count, frequency range, and impedance
msx touchstone inspect BandpassFilter.s2p

# Run pre-flight linting and validity checks
msx touchstone lint BandpassFilter.s2p

# Verify S-parameter passivity and compute maximum singular value
msx touchstone passivity BandpassFilter.s2p

# Fit rational state-space macromodel via Vector Fitting
msx touchstone fit BandpassFilter.s2p --order=6

# Lower state-space model to ModelScript linear DAE arena
msx touchstone to-dae BandpassFilter.s2p

# Project into Modelica 3.x electrical analog component
msx touchstone to-modelica BandpassFilter.s2p -o FilterModel.mo
