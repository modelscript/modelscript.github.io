SPICE Electronics & Analog Circuit Simulation ​

ModelScript features high-performance native support for SPICE (.cir, .sp, .net, .lib) netlists and analog circuit analysis. Engineers can validate electrical schematics, detect topological faults (floating nodes, voltage source loops), execute pure in-WASM circuit simulations, and export to Modelica or ECAD netlist graphs.

Capabilities & Supported Formats ​

FormatExtensionDescription
SPICE Netlist.cir, .sp, .netCircuit description specifying passive components (R, L, C), active semiconductors (diode, BJT, MOSFET), independent/dependent sources, subcircuits, and simulation directives.
SPICE Model Library.lib, .modDevice physics parameters for transistors, diodes, op-amps, and macro-models.

Key Architectural Features ​

  • Engineering Unit Netlist Parser:
    • Robust lexer parsing metric prefixes (f, p, n, u, m, k, meg, g, t), curly brace math expressions {R1 * 2}, line continuations (+), and subcircuit definitions (.SUBCKT / .ENDS).
    • Lossless round-trip serializer (serializeSpice()).
  • Native Numerical Solvers:
    • DC Operating Point (.OP): Assembles Modified Nodal Analysis (MNA) matrix Gv=i with Newton-Raphson iteration for non-linear PN junctions.
    • Transient Simulation (.TRAN): Numerical companion-circuit integration supporting Trapezoidal rule with damping for reactive elements (L,C).
    • AC Small-Signal Frequency Sweep (.AC): Complex admittance matrix Y(jω) solving decade/octave/linear frequency sweeps and bode response.
  • Circuit Linter Rules (M7101–M7109):
    • Identifies single-connection floating nodes, parallel ideal voltage sources, cutsets of ideal current sources, non-positive passives, and subcircuit pin mismatches.
  • Bilateral Modelica & ECAD Projections:
    • Translates SPICE netlists to standard Modelica.Electrical.Analog components.
    • Projects to generic NetlistGraph data structures for PCB layout, schematic capture, and Design Rule Checking (DRC).

Command Line Interface (msx spice) ​

bash
msx spice <action> [files...] [options]
ActionDescriptionKey Options
inspectDumps circuit netlist statistics, components, nodes, subcircuits, and directives.—
lintRuns pre-flight electrical topology checks and floating node analysis.—
opComputes DC operating point node voltages and branch currents.—
tranRuns time-domain transient analysis.--stop=<sec>, --step=<sec>, --out=<file.csv>
acRuns small-signal AC frequency sweep.--fstart=<hz>, --fstop=<hz>, --points=<num>, --type=dec|oct|lin, --out=<file.csv>
to-modelicaProjects SPICE netlist to standard Modelica.Electrical.Analog.--out=<file.mo>
to-daeLowers netlist directly into DAEBuilder SoA linear memory arena.—

Examples ​

bash
# Calculate DC bias voltages on all circuit nodes
msx spice op LowPassFilter.cir

# Simulate transient step response and export trajectory
msx spice tran PowerSupply.cir --stop=0.01 --step=1e-6 --out=transient.csv

# Run AC frequency response analysis from 10 Hz to 1 MHz
msx spice ac AudioAmplifier.sp --fstart=10 --fstop=1e6 --points=100 --out=bode.csv

# Lint netlist for floating electrical nodes and ground connectivity
msx spice lint SensorFrontEnd.net

Electrical Linters & Diagnostic Rules ​

CodeIdentifierSeverityDescription
M7101floating-nodeErrorElectrical node has only one connected pin; floating circuit hazard.
M7102parallel-voltage-sourcesErrorLoop of ideal voltage sources with zero series impedance violates KVL.
M7103series-current-sourcesErrorCutset of ideal current sources with unequal branch currents violates KCL.
M7104unresolved-subcircuitErrorSubcircuit invocation (X...) references a .SUBCKT name absent from netlist.
M7105invalid-passive-valueErrorResistance, capacitance, or inductance is non-positive or non-finite.
M7106transient-step-violationWarningTransient maximum step size TSTEP is larger than total simulation duration TSTOP.
M7107duplicate-component-nameWarningMultiple circuit components share an identical reference designator.
M7108missing-model-definitionErrorSemiconductor device references a .MODEL card that is not defined.
M7109subcircuit-pin-count-mismatchErrorNumber of pins on subcircuit instance does not match .SUBCKT header declaration.
