URDF & Xacro Robot Kinematics ​

ModelScript provides first-class support for URDF (.urdf) and Xacro (.xacro), the robotics industry and ROS (Robot Operating System) standard for describing kinematic trees, inertial properties, visual geometry, and joint limits of robotic manipulators, humanoids, and autonomous vehicles.

Capabilities & Supported Formats ​

FormatExtensionDescription
Unified Robot Description Format.urdf, .xmlXML schema defining kinematic links, joints (revolute, continuous, prismatic, fixed, floating, planar), inertial parameters, collision bounds, and visual meshes.
Xacro Macro Template.xacroParametric XML preprocessor adding variables (<xacro:property>), mathematical expressions, and reusable macros (<xacro:macro>).

Key Architectural Features ​

  • Xacro Expansion & Parser:
    • Robust XML reader with automatic in-memory macro expansion (<xacro:macro>) and mathematical expression evaluation before parsing.
    • Generates strongly typed robot AST representation via parseUrdf().
  • Topological Kinematic Tree & Featherstone Algorithms:
    • Traverses joint-link connectivity starting from the root base link.
    • Implements Recursive Newton-Euler Algorithm (RNEA) for inverse dynamics: calculates required joint torques τ given joint positions q, velocities q˙, and accelerations q¨.
    • Implements Articulated-Body Algorithm (ABA) for forward dynamics: evaluates forward acceleration q¨=M(q)−1(τ−C(q,q˙)−g(q)) in O(N) operations.
  • Robotics Linters (M7501–M7510):
    • Detects dangling parent/child link references, disconnected kinematic sub-trees, inverted joint limits (lower > upper), zero joint axis vectors, missing inertia tags, and non-physical inertia tensors.
  • Multi-Target Projections:
    • Modelica MultiBody: Synthesizes Modelica.Mechanics.MultiBody robotic arms with joint friction and actuator controllers.
    • MSC Adams: Exports Adams .adm solver datasets.
    • SIMPACK: Generates SIMPACK .spck mechanisms.
    • 3D CAD: Projects robot geometry into CSG primitives and STEP visual meshes.

Command Line Interface (msx urdf) ​

bash
msx urdf <action> [files...] [options]
ActionDescriptionKey Options
inspectDumps robot name, root link, joint tree, mass budget, and degrees of freedom.—
lintRuns kinematic tree validation, joint limit checks, and inertia verification.—
dynamicsEvaluates forward (ABA) or inverse (RNEA) dynamics at test joint coordinates.--q=<csv>, --qd=<csv>, --qdd=<csv>, --tau=<csv>
to-modelicaGenerates standard Modelica.Mechanics.MultiBody robot system.--out=<file.mo>
to-adamsProjects robot mechanism into MSC Adams .adm solver dataset.--out=<file.adm>
to-simpackProjects robot mechanism into SIMPACK XML .spck model.--out=<file.spck>
to-daeLowers kinematic state equations directly into DAEBuilder arena.—

Examples ​

bash
# Inspect robot kinematic hierarchy and total mass
msx urdf inspect KukaIiwa14.urdf

# Check for inverted joint limits or dangling parent links
msx urdf lint MobileManipulator.urdf

# Convert robot description into standard Modelica 3.x
msx urdf to-modelica PandaArm.urdf --out=PandaArm.mo

# Export to MSC Adams for vehicle-mounted robot simulation
msx urdf to-adams RoverArm.urdf --out=RoverArm.adm

Robotics Linters & Diagnostic Rules ​

CodeIdentifierSeverityDescription
M7501dangling-parent-linkErrorJoint references a parent link name that does not exist in the robot description.
M7502dangling-child-linkErrorJoint references a child link name that does not exist in the robot description.
M7503disconnected-kinematic-treeErrorOne or more links cannot be reached via kinematic joints from the root link.
M7504cyclic-kinematic-chainErrorJoint hierarchy contains a cycle; URDF requires a strictly acyclic tree topology.
M7505missing-inertial-tagWarningNon-fixed moving link omits <inertial> mass and inertia tensor definition.
M7506non-physical-inertiaErrorLink inertia tensor violates positive-definiteness or triangle inequality.
M7507zero-joint-axisErrorRevolute or prismatic joint specifies a zero axis vector (xyz="0 0 0").
M7508inverted-joint-limitsErrorJoint lower limit exceeds the upper limit (limit lower > upper).
M7509zero-effort-limitWarningActive non-fixed joint specifies maximum effort limit of zero.
M7510missing-visual-or-collisionInfoLink does not declare any visual or collision geometry.
